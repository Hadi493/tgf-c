## `tgf-c` *C* Implementation of [tgf-py](https://github.com/Hadi491/tgf-py)

### Quick Start

Clone The repo and configure `config.json`
```bash
cd tgf-c/

cp config.json.example config.json
```

```bash
gcc -o nob nob.c
./nob
```
