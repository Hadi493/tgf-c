## `tgf-c` *C* Implementation of [tgf-py](https://github.com/Hadi491/tgf-py)

### Quick Start

Clone The repo and configure `.env.h` & `config.h`
```bash
git clone https://github.com/Hadi493/tgf-c.git

cd tgf-c/

cp config.h.example config.h
cp .env.h.example .env.h
```

```bash
gcc -o nob nob.c
./nob
```
